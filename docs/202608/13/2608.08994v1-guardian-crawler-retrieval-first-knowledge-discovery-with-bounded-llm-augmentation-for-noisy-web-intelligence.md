## 摘要
从嘈杂的网络数据中检索相关证据具有挑战性，尤其是在包含不完整报告、异构语言和不相关内容的敏感领域。我们提出了Guardian Crawler，一个可复现的检索优先测试平台，用于在合成类网络语料库上进行受控的知识发现和基于证据的摘要实验。该架构将BM25检索与风险感知、嵌入增强和混合重排序相结合，随后进行带显式文档引用的受限检索增强生成。在包含900篇文档的合成语料库和10个查询上的实验表明，基于风险的重排序取得了最高的描述性检索分数，P@10 = 1.00，NDCG@10 = 0.94，而BM25分别为0.94和0.81。最佳的混合配置和BM25+语义配置分别达到了0.94和0.88的NDCG@10值。所有41个可评估的生成要点均通过了词汇覆盖率阈值；一个自动化的LLM裁判将其中的36个分类为受支持，1个部分支持，4个不受支持。这些结果证明了Guardian Crawler作为受控测试平台的可行性，但并未确立统计优越性、人工验证的忠实性，或对实时网络调查环境的迁移能力。

## Abstract
Retrieving relevant evidence from noisy web data is challenging, particularly in sensitive domains containing incomplete reports, heterogeneous language, and irrelevant content. We present Guardian Crawler, a reproducible retrieval-first testbed for controlled experiments on knowledge discovery and evidence-grounded summarization over synthetic web-like corpora. The architecture combines BM25 retrieval with risk-aware, embedding-augmented, and hybrid reranking, followed by constrained retrieval-augmented generation with explicit document citations. Experiments on a synthetic 900-document corpus and 10 queries produced the highest descriptive retrieval scores under risk-based reranking, with P@10 = 1.00 and NDCG@10 = 0.94, compared with 0.94 and 0.81 for BM25. The best hybrid and BM25+Semantic configurations reached NDCG@10 values of 0.94 and 0.88, respectively. All 41 evaluable generated bullets passed the lexical coverage threshold; an automated LLM judge classified 36 as supported, one as partially supported, and four as unsupported. These results demonstrate the feasibility of Guardian Crawler as a controlled testbed but do not establish statistical superiority, human-validated faithfulness, or transfer to live-web investigative environments.

## 2. 论文提出的方法论

### 核心设计思想
- **三个设计目标**：
  - **可复现性**：实验可在已知文档类型、链接结构和相关性启发规则的受控语料上重新运行。
  - **模块化**：检索、生成、标签、嵌入和评估可独立检查和替换。
  - **受限性**：LLM 仅在可能增值的环节使用，不作为爬取、索引或排序的不透明替代品。

### 系统架构（端到端模块化流水线）
- **配置层**：设置共享默认参数。
- **迷你网络生成器**：从结构化案例种子生成静态 HTML 语料，分配四类页面（公告、新闻、噪声、不相关），构建带同类链接偏置和可达性约束的可爬取图。
- **HTML 提取器 / 爬虫**：标准化原始页面，广度优先爬取，URL 规范化，深度和页数限制，基于哈希去重。
- **BM25 索引**：作为第一阶段检索的统一词法基线。
- **标签层**：LLM 按固定 JSON 模式对页面做粗粒度类型标注。
- **风险感知重排序器**：基于 28 条危害相关词表，提升与风险相关的词法信号。
- **语义重排序器**：基于嵌入相似度对 BM25 候选集进行重排（非独立密集检索器）。
- **排序比较器**：统一框架下公平比较所有排序条件。
- **RAG 层**：将检索到的证据转换为带引用 ID 的要点列表，证据不足时允许"弃权"。
- **评估层**：分别对检索效果和依据（grounding）进行评分。

### 关键公式与技术细节
- **BM25 参数**：k1 = 1.2，b = 0.75，min_doc_tokens = 3；IDF 公式为 log((N−df+0.5)/(df+0.5)+1)，查询词按集合（而非多重集合）处理。
- **风险评分**：RiskRaw(d) = Σ_t w_t · min(tf_t(d), 2)，RiskScore(d) = RiskRaw(d) / (RiskRaw(d) + 3)。
- **三种排序公式**：
  - Score_risk(d,q) = (1−α)·BM25̂(d,q) + α·Risk(d)
  - Score_sem(d,q) = (1−λ)·BM25̂(d,q) + λ·Sem̂(d,q)
  - Score_hybrid(d,q) = wB·BM25̂ + wR·Risk + wS·Sem̂
- **重要约束**：所有重排序条件共享同一个 BM25 候选集（实验中为全部 900 篇文档），从而隔离评分和重排序行为，而非比较不同候选召回。
- **LLM 的四个受限角色**：语料构建、页面标注、带引用摘要生成、自动依据评估。生成器与裁判分离，但同为 Gemini 模型。

- **检索效果**：

  - 最佳混合条件（0.4, 0.3, 0.3）达到 P@10 = 0.99，NDCG@10 = 0.94。
  - 最佳 BM25+Semantic（λ=0.6）达到 P@10 = 0.97，NDCG@10 = 0.88。
- **语义对齐**：BM25+Semantic 的 SR@10（0.57）最高，说明嵌入信号在语义邻近性上有互补价值，尽管未最大化主检索指标。
- **生成依据**：
  - 41/41 条要点通过词法覆盖阈值（100% 词法支持）。

- **核心发现**：词法覆盖 ≠ 忠实性。词法重叠高并不一定意味着生成内容被证据充分支持，系统设计显式地区分了这两个维度。
- **总体定性**：结果支持 Guardian Crawler 作为受控测试床的可行性，但**不构成**统计优越性、人工验证的忠实性或实时网络效力的证据。

## 7. 优点

- **检索优先架构**：将 LLM 限制在明确的辅助角色（标注、生成、评估），而非端到端模糊替代检索流程，降低了黑箱风险。
- **共享候选池设计**：所有条件在同一候选集上重排序，隔离了重排序行为差异，对比更加公平和可解释。
- **分层评估**：将检索质量与生成依据分开评估，且依据评估又分确定性的词法检查与语义性的 LLM 裁判两层，揭示了"词法覆盖≠语义支持"的重要洞察。
- **可控性与可复现性**：完全合成的语料 + 规则派生的 qrels + 缓存机制，保证实验可精确重现，规避了实时数据带来的伦理与隐私问题。
- **受限的 LLM 使用**：生成允许"弃权"（abstain），体现了负责任的 AI 设计。
- **诚实的方法论定位**：作者反复强调结果仅为描述性、不构成统计证明，对结论边界有清晰的自觉。

## 8. 不足与局限

- **合成语料的局限**：无法复现真实网络的动态漂移、对抗性内容、损坏的标记、多语言变化等复杂性，结果不能直接推广到实时环境。
- **规模过小**：900 篇文档、10 条查询，不足以支撑稳健的宏观平均，限制了泛化性主张。
- **缺少统计显著性检验**：无配对检验、置信区间或置换检验，各配置间的差异可能是噪声。
- **评估偏差风险**：
  - qrel 规则与风险词表编码相同领域线索，未测量的重叠可能人为抬高风险感知排序的表现。
  - LLM 裁判是模型评估而非人类评估，存在提示敏感性、分类偏差和模型固有脆弱性。
  - Gemini 参与多个环节，虽有程序分离但缺少模型族独立性。
- **领域特异性**：风险词表、查询集和文档类型均针对失踪儿童/人口贩卖场景定制，风险感知排序的优势可能无法迁移到其他领域。
- **比较范围有限**：没有独立密集检索器（dense retriever）或外部神经检索基线；语义嵌入仅作为重排序信号，未测试端到端密集检索。
- **生成质量缺陷**：跨文档合成存在案件混淆问题，尤其是在词法相似案例之间，这是调查情境中证据摘要的核心挑战。
- **不涉及决策效力**：未验证下游搜索规划、干预结果或实际调查效能。
