## 摘要
基于大型语言模型（LLM）的深度搜索智能体通过迭代检索和推理来解决问题，但局部相关的证据可能导致持续的错锚漂移、约束漂移或局部主题漂移。现有方法监督轨迹、结果或步骤，但很少区分与任务对齐的延续和加剧漂移的局部合理延续。我们提出BOUND，一种针对持续搜索漂移的简报引导的纠正性偏好蒸馏框架。对于每个由学生引发的决策时状态，BOUND构建一个教师端搜索状态简报，该简报保留原始搜索目标和关键约束，同时总结已确认的证据、缺失信息和漂移状态。在简报的引导下，教师判断学生的延续是否包含可能影响后续决策的可纠正的局部搜索控制错误。结合滚动（rollout）结果，该评估决定是构建学生特定纠正与原始延续之间的纠正性对比，还是构建受支持答案与不必要检索延续之间的终止性对比。每个经过验证的状态匹配偏好对都实现了一个搜索控制边界。直接偏好优化（DPO）将这些偏好蒸馏到学生模型中，而简报和教师端计算仅局限于训练阶段。我们在四个多跳问答基准和三个深度搜索基准上评估BOUND。在我们重新运行基线的六个基准中，BOUND在五个数据集和14项指标中的12项上领先。在相同的搜索控制接口和匹配设置下，BOUND在Bamboogle上比Trajectory SFT高出5.6个精确匹配（EM）点，在BrowseComp-Plus上高出4.8个准确率点。代码可在 https://github.com/RUCAIBox/BOUND 获取。

## Abstract
Large language model (LLM)-based deep search agents solve tasks through iterative retrieval and reasoning, but locally relevant evidence can cause persistent wrong-anchor drift, constraint drift, or local-topic drift. Existing methods supervise trajectories, outcomes, or steps, but rarely distinguish task-aligned continuations from locally plausible ones that reinforce drift. We propose BOUND, a brief-guided corrective preference distillation framework for persistent search drift. For each student-induced decision-time state, BOUND constructs a teacher-side search-state brief that preserves the original search target and key constraints while summarizing confirmed evidence, missing information, and drift status. Guided by the brief, the teacher determines whether the student's continuation contains a correctable local search-control error likely to affect subsequent decisions. Together with the rollout outcome, this assessment determines whether to construct a corrective contrast between a student-specific correction and the original continuation, or a termination contrast between a supported answer and an unnecessary retrieval continuation. Each validated state-matched preference pair operationalizes a search-control boundary. Direct preference optimization (DPO) distills these preferences into the student, while the brief and teacher-side computation remain confined to training. We evaluate BOUND on four multi-hop QA benchmarks and three deep-search benchmarks. Across the six benchmarks for which we reran baselines, BOUND leads on five datasets and 12 of 14 metrics. Under the same search-control interface and matched settings, BOUND outperforms Trajectory SFT by 5.6 EM points on Bamboogle and 4.8 accuracy points on BrowseComp-Plus. Code is available at https://github.com/RUCAIBox/BOUND.

## 一、论文的核心问题与整体含义（研究动机和背景）

**核心问题：** 基于大语言模型（LLM）的深度搜索智能体通过迭代检索与推理解决复杂问题，但在多步搜索过程中，即使每一步的检索结果都局部相关，也可能逐步累积误导信息，导致智能体偏离原始搜索目标或丢失关键约束，从而产生**持续性搜索漂移**。

**三种典型漂移形式：**
- **错锚漂移（Wrong-Anchor Drift）**：检索证据引入的相关实体成为新的搜索锚点，导致智能体追踪错误目标（如转而搜索Lenard而非爱因斯坦）；
- **约束漂移（Constraint Drift）**：搜索过程中丢失时间、奖项条件等关键限定词（如丢失"1921年""诺贝尔奖"等约束）；
- **局部主题漂移（Local-Topic Drift）**：检索结果将智能体带向局部连贯但全局偏移的旁支主题（如探索光电效应历史而非回答物理学家毕业城市）。

**现有方法的不足：**
- 轨迹级后训练（Trajectory SFT）依赖完整教师轨迹，对上下文诱发的偏差缺乏指导；
- 结果强化学习（Outcome RL）在长交互中分配粗粒度信用；
- 细粒度过程监督方法（如查询质量、信息获取信号）虽能识别局部行为质量，但**局部合理的动作可能延续已有偏差的轨迹**，使搜索保持连贯却持续偏离任务。

**论文提出：** BOUND框架，通过教师侧**搜索状态简报**锚定原始搜索目标与关键约束，在决策时状态下纠正学生延续中的局部搜索控制错误，并通过DPO蒸馏偏好，在不改变推理时输入的前提下有效抑制搜索漂移。

## 二、论文方法论：核心思想与关键技术

### 2.1 核心思想

BOUND的核心在于识别并操作化**搜索控制边界**——即在相同学生可见状态下，不同延续蕴含不同局部搜索控制决策，且决策时证据支持可靠偏好判断的决策点。每个验证过的状态匹配偏好对即实现一个搜索控制边界。

### 2.2 方法论流程

**1. 学生轨迹生成**：初始策略 π₀ 与检索环境交互，生成轨迹
τ(π₀, q) = {(sₜ, yₜ⁰, oₜ)}，其中：
- sₜ = (q, Hₜ, Cₜ)：学生可见状态（问题、动作历史、活动证据上下文）；
- yₜ⁰：学生的原始延续（thought + action + parameter）；
- oₜ：检索观察（若动作是检索）。

**2. 搜索状态简报构建**：对于每个决策时状态，教师构建结构化简报 bₜ = g_B(sₜ)，包含五个字段：
- **Original Search Target**（原始搜索目标）；
- **Key Constraints**（关键约束）；
- **Confirmed Evidence**（已确认证据）；
- **Missing Information**（缺失信息）；
- **Drift Status**（漂移状态）。

简报将任务不变的要求与状态相关搜索进展分离，提供任务锚定的参考，防止教师被已漂移的上下文"同化"。

**3. 决策时评估（AssessAndCorrect）**：教师基于 (sₜ, bₜ, yₜ⁰) 判断学生的原始延续是否包含特定局部搜索控制错误，输出评估记录 dₜ = (zₜ, ρₜ, eₜ)，其中：
- zₜ：辅助路由标签（evidence_completion / target_maintenance / answerability / not_selected）；
- eₜ：错误指示（0或1）；
- 若 eₜ=1 且 zₜ≠not_selected，则生成学生特定纠正 ỹₜ^T = Correct(sₜ, bₜ, dₜ, yₜ⁰)。

**4. 结果条件化的对比构造**（结合滚动结果 r）：
- **不成功轨迹（r=0）**：当存在错误且有可靠纠正时，构造 (yₜ⁺, yₜ⁻) = (ỹₜ^T, yₜ⁰)，即学生特定纠正 vs 原始延续；
- **成功轨迹（r=1）**：找到最早的受证据支持的回答步骤 t\*，构造 (yₜ⁺, yₜ⁻) = (yₜ⁰, UnnecessaryRetrieval(sₜ, bₜ, yₜ⁰))，即受支持答案 vs 不必要检索延续；
- 无可靠偏好的状态不产生对比对（教师可弃权）。

**5. 验证与筛选**：每个偏好对必须通过验证——格式合法、与构建路径一致、动作或参数有实质差异、不含教师专用信息（简报、评估记录、滚动结果等）、终止对中被拒绝动作必须调用检索。

**6. DPO训练**：使用初始策略 π₀ 作为参考策略，通过DPO优化学生：最大化 P(y⁺|sₜ) 并最小化 P(y⁻|sₜ)。偏好数据集由 983 个训练问题产生 2,424 个步级偏好对。

**7. 推理**：仅需学生可见状态 sₜ，简报与教师计算均不出现在推理中。

### 2.3 关键设计特点

- **学生特定纠正**：纠正条件化于学生原始延续和识别出的局部错误，而非生成泛化教师延续；
- **状态匹配对比**：偏好对共享相同状态，隔离局部搜索控制决策本身；
- **双信号结合**：简报引导的评估与滚动结果共同决定对比形式，避免将不成功轨迹中所有决策视为错误；
- **Reroute执行机制**：采用Reroute动作时，计算重路由查询与上一轮检索段落之间的E5嵌入余弦相似度（阈值0.2），过滤相关段落，再对新查询发起新检索。

## 六、主要结论与发现

1. **整体性能领先**：在重跑基线的6个数据集中，BOUND在5个数据集和14项指标中的12项上表现最优，超越所有4B和7B训练基线（除2Wiki上的两个7B模型）；
2. **相比Trajectory SFT**：在相同接口下，BOUND在Bamboogle上高出5.6 EM、6.5 F1，在BrowseComp-Plus上高出4.8准确率，差异在 p<0.001 水平下显著；
3. **优于ORBIT-4B**：在全部指标上超越同规模GRPO训练的ORBIT-4B；
4. **跨任务迁移能力**：仅用多跳与合成问题训练，即可在FRAMES、GAIA、BrowseComp-Plus等深度搜索任务上表现出色（BOUND在FRAMES上F1达24.7，GAIA上F1达40.8），且超过部分大模型系统（如DeepSeek-R1-0528、Search-R1-32B、WebSailor-32B等）；
5. **重路由监督是关键**：移除Reroute后BrowseComp-Plus准确率从29.6降至21.2，表明显式重新锚定对持续偏差至关重要；
6. **教师简报有效**：两种教师下加入简报均提升下游学生性能，主要在于提高漂移状态评估精度（从75.0%升至91.7%）并减少误报（4→1）；
7. **双信号互补**：简报引导评估与滚动结果结合优于仅用任一信号的策略。

4. **人工评估样本量小**：简报保真度与教师评估质量仅基于50个状态的检查，且在漂移状态与非漂移状态之间的分类标准存在一定主观性；
5. **教师模型依赖**：评估局限在DeepSeek-V4-Flash和Qwen3-32B两种教师，更弱或更强的教师影响未探讨；

7. **检索配置耦合**：依赖BM25+E5+RRF的混合检索器，不同检索环境下的泛化未验证；
