## 摘要
约束机器学习能够实现公平性感知训练、物理信息神经网络以及将符号领域知识整合到统计模型中。尽管具有实际重要性，但对于深度学习中自然出现的非凸、非光滑、随机场景，尚无通用方法。我们提出随机惩罚-障碍方法（SPBM），通过指数对偶平均、稳定的惩罚调度以及处理非光滑性的Moreau包络，将经典惩罚和障碍方法扩展到该场景。在多种设置下的实验表明，SPBM在匹配或超越现有约束优化基线的同时，相较于无约束Adam，对于多达10,000个约束仅产生线性运行时开销。

## Abstract
Constrained machine learning enables fairness-aware training, physics-informed neural networks, and integration of symbolic domain knowledge into statistical models. Despite its practical importance, no general method exists for the non-convex, non-smooth, stochastic setting that arises naturally in deep learning. We propose the Stochastic Penalty-Barrier Method (SPBM), which extends classical penalty and barrier methods to this setting via exponential dual averaging, a~stabilized penalty schedule, and the Moreau envelope to handle non-smoothness. Experiments across multiple settings show that SPBM matches or outperforms existing constrained optimization baselines while incurring only linear runtime overhead compared to unconstrained Adam for up to 10,000 constraints.

约束机器学习（CML）在公平性训练、物理信息神经网络（PINNs）以及整合符号领域知识等场景中至关重要。然而，现有方法大多假设确定性或凸性约束，无法有效处理深度学习中普遍存在的**非凸、非光滑、随机**约束问题。本文旨在提出一种通用的、高效的随机优化方法，能够处理如下形式的问题：

\[
\min_{x \in \mathbb{R}^n} \mathbb{E}[f(x,\xi)] \quad \text{s.t.} \quad \mathbb{E}[g(x,\xi)] \leq 0
\]

其中目标函数和约束函数均为非凸、非光滑、随机。论文将经典的罚-障碍方法（PBM）扩展到该场景，为深度学习的约束优化提供了一种可行的解决方案。

### 论文提出的方法论

**核心思想**：将PBM的确定性迭代框架迁移到随机环境，并通过三项关键修改克服非光滑性和小批量噪声带来的挑战。

**关键技术细节**：

1. **指数移动平均对偶更新**：用指数衰减平均替代原始PBM中的直接对偶更新，以降低小批量采样的噪声：
   \[
   \lambda_{k+1} = \gamma\lambda_k + (1-\gamma)\lambda_k \odot \varphi'\left(\frac{g(x_k)}{p_k}\right)
   \]
   其中\(\varphi\)为罚-障碍函数（如Quadratic-Logarithmic或Quadratic-Reciprocal），\(\gamma\)为衰减率。

2. **稳定性罚项调度**：原始PBM中罚参数\(p\)单调递减至0易导致不稳定性，本文提出两种稳定更新策略：
   - **线性衰减**：\(\hat{\pi}_{\text{linear}}(g,p) = \text{Clip}_{[0.1,1]}[K_1 p]\)，\(K_1=0.99\)。
   - **自适应衰减**：\(\hat{\pi}_{\text{adaptive}}(g,p) = \text{Clip}_{[0.1,1]}\left[\left(K_2 + (1-K_2)\frac{\varphi'(g)+\epsilon}{1+\epsilon}\right)p\right]\)，根据约束满足程度动态调整。

3. **Moreau包络处理非光滑性**：对增广拉格朗日函数进行Moreau包络平滑，然后执行一次Adam步骤作为近似近端梯度更新。具体地，优化目标为：
   \[
   \min_x \left[ \mathcal{L}_{p_{k+1}}(x,\lambda_{k+1}) + \frac{\mu}{2}\|x - s_k\|^2 \right]
   \]
   其中\(s_k\)通过指数平均更新：\(s_{k+1} = \delta s_k + (1-\delta)x_{k+1}\)。

**算法流程**（文字描述）：
- 初始化：\(x_0, \lambda_0 > 0, p_0 = 1\)，以及其他超参数。
- 每轮迭代：
  1. 采样小批量数据，计算随机梯度。
  2. 更新对偶变量\(\lambda_{k+1}\)（指数移动平均）。
  3. 更新罚参数\(p_{k+1}\)（线性或自适应）。
  4. 计算Moreau梯度和近似近端梯度：\(y_k = \nabla \mathcal{L}_{p_{k+1}}(x_k,\lambda_{k+1}) + \mu(x_k - s_k)\)。
  5. 使用Adam更新原始变量\(x_{k+1}\)。
  6. 更新近端中心\(s_{k+1}\)。

### 论文的主要结论与发现

1. **SPBM与SSL-ALM竞争力相当**：在8个实验中，SPBM在3个实验中优于SSL-ALM（尤其是高约束数量的CIFAR-100和PINNs），其余5个实验持平。表明SPBM是可靠的替代方案。
2. **多约束专用方法优于单约束方法**：SSw仅处理单约束，在多数实验中表现最差；而SPBM和SSL-ALM作为多约束方法明显更优。
3. **约束训练计算可行**：SPBM的运行时开销相对于无约束Adam仅为线性因子（≤3倍），且对于10,000个约束亦可处理。
4. **PINNs中约束处理对解质量至关重要**：SPBM在亥姆霍兹和Burgers方程上获得了更小的测试误差和更好的约束满足，优于Adam（正则化）和SSL-ALM。
