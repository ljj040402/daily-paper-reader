## 摘要
深度强化学习（RL）的最新进展表明，改进神经网络架构可以在不改变底层算法的情况下，显著提高样本效率和渐近性能。相比之下，多目标强化学习（MORL）旨在发现一组在相互冲突的目标之间权衡折中的策略，其相关工作主要集中在算法创新上，而架构领域仍未得到充分探索。尽管最优策略和价值函数会因权衡折中而显著不同，但MORL算法通常使用以权衡为条件的简单前馈网络来表示它们。这就提出了一个问题：使用更具表达力的函数逼近器是否能提高算法的性能。在本文中，我们整合了神经网络设计的最新进展：（i）观测与特征归一化，（ii）权重归一化，以及（iii）使用熵正则化的MORL算法对分布回报进行建模。在标准连续控制基准上的实证结果表明，这些改变在不需要对底层算法进行重大修改的情况下，显著提高了所生成的解集的质量。

## Abstract
Recent advances in deep reinforcement learning (RL) have shown that improving neural network architectures can yield substantial gains in sample efficiency and asymptotic performance without altering the underlying algorithms. In contrast, work on multi-objective reinforcement learning (MORL), which aims to discover a set of policies that balance trade-offs among conflicting objectives, has predominantly focused on algorithmic innovations, leaving the area of architectures underexplored. While the optimal policies and value functions can differ significantly depending on the trade-offs, MORL algorithms commonly represent them with simple feedforward networks conditioned on the trade-off. This raises the question of whether the performance of the algorithms could be improved with more expressive function approximators. In this paper, we integrate recent advances in neural network design: (i) observation and feature normalization, (ii) weight normalization, and (iii) modeling of distributional returns with an entropy-regularized MORL algorithm. The empirical results across standard continuous control benchmarks demonstrate that these changes substantially improve the quality of the produced solution sets without requiring major changes to the underlying algorithm.

### 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：深度强化学习（RL）的最新进展表明，改进神经网络架构可以在不改变算法本身的情况下显著提升样本效率和渐近性能；但在多目标强化学习（MORL）领域，研究工作几乎全部集中在算法创新上，网络架构的设计长期被忽视。

### 2. 方法论：核心思想、关键技术与算法流程

#### 2.1 核心思想
以熵正则化的通用策略方法 CAPQL（Lu et al., 2023）作为底层算法，将单目标 RL 中 SimbaV2 架构（Lee et al., 2025b）的三项关键技术迁移至多目标场景，在不改变底层算法框架的前提下提升解集质量。

#### 2.2 三大关键技术组件
1. **观测与特征归一化（Observation & Feature Normalization）**
   - 使用运行统计归一化（RSNorm）将观测各维度归一化到零均值、单位方差。
   - 将归一化后的观测映射到单位超球面（L2Norm），并拼接正数常数以保留幅度信息。
2. **权重归一化（Weight Normalization）**
   - 将线性层权重约束在单位超球面上，每次梯度更新后执行 L2Norm。
   - 引入可学习的缩放向量和可学习残差连接（LERP 插值层）。
3. **分布回报建模（Distributional Critic，多目标 C51 风格）**
   - **关键适应策略**：作者指出 critic 预测仅通过标量化 Q 值 $ω^\top Q(s, a, ω)$ 影响策略优化，因此**无需建模多变量联合回报分布**，而是直接学习标量化回报的**一维分布**。
   - 模型通过交叉熵（CE）损失训练：
     $$L_Z(\theta) = \mathbb{E}_{(s,a,r,s',\omega)\sim\mathcal{D}}\; H\big(\hat{Z}(\omega^\top r, s'), Z_\theta(s,a,\omega)\big)$$
   - 行动者（actor）最大化期望标量化分布回报：$\mathbb{E}_{a\sim\pi_\phi}\big[\mathbb{E}[Z_\theta(s,a,\omega)]\big] + \alpha H(\pi_\phi(\cdot|s,\omega))$
   - 奖励按各分量最大观测回报进行归一化，使回报落入分布 critic 的支撑区间。

#### 2.3 偏好采样策略
- 作者刻意**放弃复杂的偏好选择算法**（如 GPI-LS 的偏好优先级机制），仅简单地在每个 episode 开始时从均匀分布（Dirichlet 分布）采样一次偏好。
- 这一简化凸显了架构改进贡献的纯粹性，说明性能提升无需依赖复杂偏好采样策略。

#### 2.4 算法流程（文字概括）
在每个 episode 开始时采样偏好 ω → 在环境中执行策略收集轨迹 → 从回放缓冲区采样批次 → 用交叉熵损失更新两个 Q 网络（分布 critic） → 用策略梯度更新 actor（最大化标量化 Q 值与熵正则项） → 软更新目标网络参数。相比原版 CAPQL，仅修改了 critic 损失类型和偏好采样频率。

### 3. 实验设计：数据集、基准与对比方法

#### 3.1 基准环境
- 使用 **MuJoCo 物理引擎**实现的 **7 个连续控制任务**（源自 Xu et al. 2020）：
  - Ant-v4、HalfCheetah-v4、Hopper-v4（2 目标）、Hopper-v3（3 目标）、Humanoid-v4、Swimmer-v4、Walker2d-v4。
- 各环境目标包括 x/y 方向速度、能量效率、跳跃高度等，均为标准 MORL 连续控制基准。

#### 3.2 评估指标
- **Hypervolume（HV，主指标）**：衡量解集的收敛性、均匀性与延展性。
- **Expected Utility Metric（EUM）**：衡量解集对用户期望效用的覆盖能力。
- 聚合结果采用 **IQM（四分位均值）** 和 **95% 分层自助置信区间（SBCIs）**，遵循 Agarwal et al. (2021) 的推荐。

#### 3.3 对比基线（4 个）

|---|---|---|
| CAPQL | 通用策略（底层算法） | 1M |
| PGMORL | 多策略（进化算法） | 12M–120M |
| DPMORL | 多策略（分布 Pareto） | 10M |
| GPI-LS | 通用策略 + GPI 偏好选择 | 200k |

每项实验在 **10 个随机种子**上运行（GPI-LS 对比实验为 7 个种子）。

### 6. 主要结论与发现

1. **架构改进带来显著性能提升**：Momba 在聚合 HV 上比 runner-up（PGMORL）提升约 **35%**，在 EUM 上提升约 **16%**；与底层算法 CAPQL 相比，HV 提升约 **132%**，EUM 提升约 **35%**。
2. **样本效率大幅提高**：在 Ant 和 Humanoid 任务中，Momba 仅需 100k 和 200k 步即达到 PGMORL 的最终性能；在相同 UTD 比例下（如 UTD=1），Momba 的样本效率优于 GPI-LS。
3. **分布 critic 是核心贡献组件**：即使在标准 MLP 架构下，引入 CE 损失（MLP+CE）也能匹配甚至超越 Simba+MSE 的性能，说明分布 critic 本身带来了最大增益。
4. **观测归一化是最关键的正则化技术**：Shapley 值分析显示，观测归一化贡献约 **54.8%** 的改进，特征归一化和权重归一化分别贡献约 24.8% 和 20.4%，三者具有协同效应。
5. **标量化回报分布建模是简单有效的策略**：直接学习标量化回报分布与学习各分量的向量分布（附录 B）性能几乎完全一致，验证了该近似方法在常见线性标量化假设下的适用性。
6. **性能增益并非来自参数数量的增加**：在随机种子、参数量匹配的条件下，标准 MLP+MSE 无论参数量如何增大均保持低性能，证明提升源自分布表征与架构改进。

### 7. 优点（方法或实验设计的亮点）

- **方法简洁、可迁移性强**：不发明新的 MORL 更新规则，仅将已验证的架构技术适配到现有算法，移植门槛低。
- **分布 critic 适应思路巧妙**：抓住“critic 仅经标量化影响策略”的结构特征，将多变量分布学习简化为单变量标量化分布学习，避免了对多变量联合分布核距离等复杂机制的需求。
- **实验设计严谨**：
  - 采用 IQM + SBCIs 的统计方法，避免均值受异常种子影响；

  - 使用 Shapley 值量化各归一化组件的边际贡献，分析深度超过同类论文；
  - 解集可视化弥补了 HV/EUM 在多样性度量上的不足。
- **偏好采样刻意简化**：设计上排除复杂偏好选择算法的干扰，使结论更纯粹地归因于架构改进。
- **诚实披露基线复现困难**：对 DPMORL 复现结果异常给出了具体原因分析（代码与论文差异、归一化值缺失等），体现了学术透明度。

### 8. 不足与局限

- **理论适用范围受限**：
  - 仅在线性标化框架下验证，分布 critic 的 TD 学习目标在非线性标化下可能不成立。
  - 分布 critic 建模的是标量化回报的一维分布，无法直接支持需要向量分布信息的方法（如 envelope 风格算法）；附录 B 虽提供向量扩展方案，但主文未深入分析其代价。
- **基准覆盖有限**：
  - 全部为连续控制任务，未涉及离散环境（尽管作者给出了辩解理由——现有离散 MORL 基准状态/动作空间过小，函数逼近可能不是瓶颈）。
  - 目标维度集中在 2 目标（仅 1 个 3 目标任务），对高维目标空间的扩展性未知。
  - Swimmer 环境中 Momba 未能超越 PGMORL。作者解释为通用策略方法在该环境下不适应目标难度高度不均的任务，但也说明方法存在场景依赖。
- **运行成本增加**：更表达力的网络增大墙钟时间；作者提出可用 JIT 编译或 XQC 架构缓解，但未提供量化对比。
- **基线公平性存疑**：GPI-LS 训练步数较少（200k），虽然匹配其默认协议，但并非完全同训练预算下的公平对比；DPMORL 的复现问题可能使对比结果偏差。
- **未进行超参数敏感性分析**：作者承认未做大规模超参数搜索，离散原子数、支撑区间（[−5,5]）、奖励归一化系数等关键超参数的影响未被充分探讨。
- **缺少时序与扩展性细节**：没有报告 Momba 在不同计算资源下的训练时间、推理开销以及更高目标维度时的性能衰减曲线。
