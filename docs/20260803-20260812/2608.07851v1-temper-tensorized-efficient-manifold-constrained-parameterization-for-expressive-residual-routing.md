## 摘要
残差连接依赖于静态的残差通路，对于训练深度神经网络至关重要。超连接（HC）通过整合多个残差流并学习动态信息流来增强残差路由的表达能力，而流形约束变体（mHC）则通过双随机残差混合来稳定训练。然而，现有方法中仍存在一个生成器级别的瓶颈：它们使用密集、无结构的生成器进行分支前聚合、残差混合和分支后重新分配，导致参数量随流数量快速增长。为解决此问题，我们提出了用于表达性残差路由的张量化高效流形约束参数化（TEMPER），它将这些生成器表示为输入流、特征和输出流模式上的多路张量，并使用张量网络对其进行参数化。这种结构化低秩公式被证明能够在显著减少参数增长的同时，保留依赖于令牌的流形约束路由接口。它还促进了可解释性和直观性，因为：i）张量秩控制学习到的路由子空间的维度，全秩恢复密集路由；同时ii）生成器近似误差限定了路由对数几率以及因此的路由块输出的差异。综合实验表明，TEMPER在语言建模和常识推理任务上与现有方法相当或更优，同时所需的额外参数显著更少。在八个残差流下，TEMPER达到了最佳CORE分数，同时使用的额外参数比mHC少约84%，从而展示了更强的性能-参数效率权衡。

## Abstract
Residual connections rely on a static residual pathway, and are essential for training deep neural networks. Hyper-connections (HC) increase the expressivity of residual routing by incorporating multiple residual streams and learning dynamic information flow, while manifold-constrained (mHC) variants stabilize training through doubly stochastic residual mixing. However, a generator-level bottleneck remains in existing methods: they use dense, unstructured generators for pre-branch aggregation, residual mixing, and post-branch redistribution, which results in parameter count growing rapidly with the number of streams. To address this issue, we propose \underline{\textbf{T}}ensorized \underline{\textbf{E}}fficient \underline{\textbf{M}}anifold-constrained \underline{\textbf{P}}arameterization for \underline{\textbf{E}}xpressive Residual \underline{\textbf{R}}outing (\textbf{TEMPER}), which represents these generators as multi-way tensors over the input-stream, feature, and output-stream modes, and parameterizes them using tensor networks. Such a structured low-rank formulation is shown to preserve token-dependent manifold-constrained routing interface while substantially reducing parameter growth. It also promotes interpretability and intuition, as: i) tensor ranks control the dimensionality of the learned routing subspace, with full ranks recovering dense routing; while ii) the generator approximation errors bound differences in routing logits and, consequently, in the routed-block outputs. Comprehensive experiments show that TEMPER matches or outperforms existing methods across language modeling and commonsense reasoning tasks, while requiring substantially fewer additional parameters. At eight residual streams, TEMPER achieves the best CORE score while using about $84\%$ fewer additional parameters than mHC, thus showing a stronger performance-parameter efficiency trade-off.

- **现有改进与瓶颈**：
  - 超连接（Hyper-Connections, HC）将残差路径扩展为多个残差流，并为每个 token 动态学习路由（聚合→混合→再分配），增强了残差路由的表达力。
  - 流形约束超连接（mHC）通过 Sinkhorn-Knopp 迭代将残差混合矩阵约束为双随机矩阵，提高了训练稳定性。
  - 后续的 mHC-lite 和 KromHC 主要改进残差混合矩阵的参数化（分别用 Birkhoff 混合和 Kronecker 积），以缓解参数量爆炸问题。
- **核心未解决问题（generator-level bottleneck）**：上述方法的**三个路由生成器**（分支前聚合 `W_pre`、残差混合 `W_res`、分支后再分配 `W_post`）仍然使用**稠密、无结构的权重矩阵**，其参数量随残差流数量 n 快速增长（mHC 为 O(n³) 量级），严重限制了可扩展性。
- **论文提出的核心问题**：能否用结构化、参数高效的替代方案替换 mHC 中的稠密非结构化路由生成器，同时保持甚至提升性能？

## 2. 提出的方法论：核心思想、关键技术细节、公式与算法流程

### 2.1 核心思想

- **张量视角重构**：mHC 的稠密路由生成器，其本质是将展平后的归一化流状态 `vec(RMSNorm(H)) ∈ R^(1×nd)` 映射到路由输出空间。TEMPER 不再展平输入，而是保留其**流（stream）和特征（feature）两个模式**，将三个生成器分别视为高阶张量：
  - `W_pre ∈ R^(n×d×n)`（输入流 × 特征 × 输出流）
  - `W_post ∈ R^(n×d×n)`
  - `W_res ∈ R^(n×d×n×n)`（两个输出流模式对应残差矩阵的行和列）
- **关键等价性（Remark 1）**：将该张量按模式展开（matricization）即可恢复原始的稠密权重矩阵，因此 TEMPER 只是改变了生成器的参数化方式，而完全保留了 mHC 原有的路由接口与流形约束。

### 2.2 两种张量化实例

**(1) TEMPER-CP**：使用 CP 分解（Canonical Polyadic），将每个生成器张量分解为若干秩一分量的外积之和：

- `W_pre = Σ u_q ∘ c_q ∘ v_q`
- `W_res = Σ u_q ∘ c_q ∘ v1_q ∘ v2_q`
- `W_post = Σ u_q ∘ c_q ∘ v_q`

其中 `u ∈ R^n`（输入流因素）、`c ∈ R^d`（特征因素）、`v ∈ R^n`（输出流因素），秩分量索引 q 在不同模式间引入结构化参数共享。

**(2) TEMPER-Tucker**：使用 Tucker 分解，每个生成器由**因子矩阵 + 小尺寸核心张量**构成：

- `W_pre = G_pre ×1 U_pre ×2 C_pre ×3 V_pre`
- `W_res = G_res ×1 U_res ×2 C_res ×3 V1_res ×4 V2_res`
- `W_post = G_post ×1 U_post ×2 C_post ×3 V_post`

计算流程分两步：
1. **压缩**：`T = U^T · Ĥ · C`，将输入投影到低维的流-特征联合子空间；
2. **路由**：将压缩后的表示与核心张量及输出因子矩阵收缩，得到路由 logits。

### 2.3 参数效率（公式 15）

固定特征维度 d 和张量秩时，各方法每层路由生成器参数量对比：

- mHC：`P = d(n³ + 2n²)`，随 n 呈 O(n³) 增长
- TEMPER-CP：`P = 3dr + 7nr`，随 n 呈 **O(n)** 线性增长
- TEMPER-Tucker：`P = 7nr_n + 3dr_d + 2r_n²r_d + r_n³r_d`，同样随 n 呈 **O(n)** 线性增长

### 2.4 理论保证

- **Theorem 1（秩与零空间维度）**：Tucker 压缩映射 `L(Ĥ) = UᵀĤC` 的秩为 `r_n × r_d`，零空间维度为 `nd − r_n·r_d`，即路由仅依赖于一个低维的流-特征子空间；增大秩可扩大该子空间，**满秩时恢复稠密 mHC 生成器**。
- **Lemma 1（生成器到 logits 的误差界）**：路由 logits 的偏差 ≤ `‖Ĥ‖_F · ‖W − W̃‖_F`，即张量近似误差直接控制路由 logits 的偏离程度。
- **Theorem 2（端到端路由块近似界）**：在 Lipschitz 和有界假设下，完整路由块的输出差异由 pre、res、post 三个生成器的近似误差线性界定，证明张量化误差可控传播。

- **任务类型差异**：
  - **TEMPER-Tucker** 在常识推理任务上最优（n=8 时平均准确率 51.3%），说明其全局核心张量能捕获更丰富的跨模式交互，适合多样化路由模式。
  - **TEMPER-CP** 在语言建模/BBH 任务上最优（n=8 时平均 27.3%），其可分离性先验和更强的参数共享可能带来更好的泛化。
- **张量化有效性的证据**：
  - 冻结 Tucker 核心导致性能下降→学习到的投影子空间本身不够，核心张量对压缩坐标间交互的适应同样关键。
  - TT 拓扑劣于 Tucker→在路由生成器上，全局核心优于链式局部核心。
  - 仅张量化 W_res 性能劣于联合张量化全部三个生成器→联合张量化三个生成器是最优策略。
- **秩不敏感性**：CP 秩从 2 到 32，CORE 分数仅从 0.184 变化到 0.189（最佳为 r=2），说明稠密生成器在该路由任务中过度参数化，低秩约束有隐式正则化效果。
- **理论结果**：张量秩显式控制路由子空间维度，满秩恢复稠密 mHC；生成器近似误差可传播到路由 logits 和块输出，且误差上界已给出。
