## 摘要
深度Q网络（DQN）通过自举式时间差分更新来学习价值函数，其中未来回报使用对下一状态动作值的贪心最大化来近似。尽管这种聚合规则有效，但它本质上对估计噪声敏感：当Q值不确定时，最大化算子确定性地偏向最大的估计值，无论其可靠性如何，从而通过自举放大误差。在这项工作中，我们提出了\textbf{后继轨迹聚合深度Q网络（SADQ）}，这是对Q学习的一种简单修改，用于规范化TD目标的形成方式。SADQ使用从学习到的动力学模型中获得的一步轨迹预测来指导候选下一状态动作之间的比较，在不改变底层学习框架的情况下，为聚合步骤引入额外结构。所得到的混合贝尔曼更新衰减了不可靠的最大值，同时在模型误差递减时保持标准的不动点。我们提供的理论分析表明，SADQ以逐点方式减少了自举引起的过估计。在实验上，与强DQN变体相比，SADQ在经典控制任务、真实世界向量环境和Atari基准测试中持续改善了训练稳定性。

## Abstract
Deep Q-Networks (DQNs) learn value functions through bootstrapped temporal-difference updates, where future returns are approximated using a greedy maximization over next-state action values. While effective, this aggregation rule is inherently sensitive to estimation noise: when Q-values are uncertain, the maximization operator deterministically favors the largest estimate, regardless of its reliability, leading to amplified errors through bootstrapping. In this work, we propose the \textbf{S}uccessor Rollout \textbf{A}ggregation \textbf{D}eep \textbf{Q}-Network (SADQ), a simple modification to Q-learning that regularizes how the TD target is formed. SADQ uses one-step rollout predictions from a learned dynamics model to guide the comparison among candidate next-state actions, introducing additional structure into the aggregation step without altering the underlying learning framework. The resulting mixed Bellman update attenuates unreliable maxima while preserving the standard fixed point under diminishing model error. We provide theoretical analysis showing that SADQ reduces bootstrap-induced overestimation in a pointwise manner. Empirically, SADQ consistently improves training stability across classical control tasks, real-world vector-based environments, and Atari benchmarks when compared to strong DQN variants.

## 1. 核心问题与整体含义

- **背景与动机**：标准的 DQN 通过自举式 temporal-difference（TD）更新学习价值函数，目标值使用 `max_a' Q(s', a')` 进行贪心聚合。该最大化算子对 Q 值估计噪声非常敏感，当 Q 值不确定时，会偏向于最大估计值而忽略其可靠性，导致过估计通过自举被反复放大，造成训练不稳定和价值函数偏差。
- **核心问题**：如何在不放弃 Q-learning 框架的前提下，缓解最大化算子带来的噪声放大，使 TD 目标构造更加鲁棒。
- **整体含义**：论文以"动作聚合"为切入点，提出利用一步动力学模型预测来引导动作选择，修正 TD 目标，在保持标准固定点的同时，降低过估计风险。

## 2. 方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想

- 不改变底层 Q-learning 框架，而是通过引入一个轻量的动力学模型 `M`，对下一状态的候选动作进行一步 rollout 预测，基于这些预测结果选择用于构造 TD 目标的动作，再与标准贪心目标进行混合加权，得到最终目标值。
- 该机制将"动作排名"与"值评估"分离：动力学模型仅用于指导选择哪个动作，而最终值仍然由 Q 网络/目标 Q 网络提供。

### 关键技术细节

1. **向量状态动力学模型**：
   - 对低维状态，直接建模 `P(s' | s, a) ≈ N(μ(s,a), σ²(s,a))`，其中 `μ`、`σ²` 由神经网络输出。
   - 使用重参数化技巧采样 `s'_M = μ(s,a) + σ(s,a)·ε`。
   - 奖励预测头 `r_M = f_r(s,a)`。
   - 训练损失：`L_M = MSE(s'_M, s') + MSE(r_M, r)`。

2. **图像状态动力学模型**：
   - 对高维图像输入，采用简化版 RSSM 风格潜在动力学模型，仅用于一步预测。
   - 包含特征模型、编码器、动力学预测器、奖励预测器、解码器。
   - 损失为加权组合：`L(φ) = β_pred L_pred + β_dyn L_dyn + β_rep L_rep`（β 取 1、1、0.1）。
   - 为减少计算开销，根据重建损失阈值 `τ_M` 自适应降低动力学模型更新频率。

3. **结构聚合目标（SADQ 核心）**：
   - 对每个候选动作 `a'`，用模型生成一步预测 `(r'_M, s''_M)`，计算模型辅助贝尔曼估计：
     `fQ'(s', a') = r'_M + γ max_{a''} Q'(s''_M, a'')`
   - 选择 `a_hat' = argmax_{a'} fQ'(s', a')`
   - 构造混合目标：
     `y_hat = α max_{a'} Q'(s', a') + (1-α) Q'(s', a_hat')`
   - 其中 `α ∈ [0,1]` 控制标准贪心目标与模型引导选择之间的插值。

4. **扩展到分布 DQN（C51/QRDQN 等）**：
   - 将向量 Q 值换成分布 `Z'`，用期望选择动作，混合目标为：
     `Z_hat = α Z'(s', a^*) + (1-α) Z'(s', a_hat')`
   - 保留分布学习框架，只改变目标中动作的选取方式。

5. **理论分析**：
   - Lemma 1：基于 NTK 的局部状态外推界，保证模型预测状态邻近时 Q 值差异有界。
   - Assumption 1：模型扰动（奖励误差 + 状态诱导值误差）有界。
   - Theorem 1：
     - (1) 混合算子 `T_mix Q ≤ T_std Q` 逐点成立，即不会比标准贪心备份更乐观，减少过估计；
     - (2) 当模型误差趋于零时，混合算子迭代后收敛到最优贝尔曼目标 `T^*Q^*`。

6. **算法流程（文字描述）**：
   - 训练循环中：
     1. 从经验回放 `D` 采样数据训练动力学模型 `M`；
     2. 重新采样数据，对每个候选动作生成一步 rollout；
     3. 选择模型引导的候选动作 `a_hat'`；
     4. 构造混合目标 `y_hat`，更新 Q 网络；
     5. 周期性更新目标网络。

- 标准 TD 目标中的硬最大化对噪声 Q 值敏感，是导致不稳定训练的一个结构性原因。
- SADQ 使用一步 roll-out 引导动作选择，构造混合 TD 目标，能够在理论上逐点降低过估计，且在模型误差趋于零时恢复最优目标。

## 8. 不足与局限

- **依赖动力学模型的质量**：方法性能在很大程度上取决于一步动力学模型的准确性；在简单环境（如 Cartpole）中，模型尚未收敛即被使用，反而导致性能下降。
- **理论保证不涵盖有限误差情况**：论文只证明了模型误差为零时的理想极限一致性，并未给出非零模型误差下混合算子的固定点偏差界，因此有限误差下是否存在系统性偏差尚不明确。
- **额外计算开销**：即使采用自适应调度，SADQ 仍然需要训练一个额外的动力学模型，比原算法增加约 20%~50% 的训练时间（Atari-100K 上从 4 分钟到 5 分钟，Atari-10M 上从 434 分钟到 522 分钟）。

- **应用范围受限**：目前仅在离散动作空间上验证，未推广到连续控制；动作空间极大（如自然语言动作或大规模动作集）时，对所有候选动作进行一步 rollout 的计算成本可能不可接受。

## 9. 总结与未来研究方向

- **方法定位**：SADQ 并不是一条全新的 RL 算法路径，而是在现有 Q-learning 框架内增加了一个“模型引导的动作选择”模块，以较小的结构改动换取训练稳定性的提升。这种“插件式”设计使得它可以被快速集成到多种骨干算法（DQN、QRDQN、IQN 等）中，具有较强的实用性和可扩展性。
- **适用场景**：实验表明，SADQ 在动作空间较大（如 CityFlow 中 256 个动作）、奖励稀疏或 Q 值噪声明显的环境中增益更显著；而在动力学模型容易学习（如 Cartpole）但值函数本身较简单的情形下，额外引入的模型误差反而会带来负收益。因此，其优势主要集中在“复杂状态转移 + 高维动作空间”的任务中。
- **理论缺口**：当前的理论保证依赖于模型误差为零的极限假设，尚缺乏对非零模型误差下混合目标偏差界的刻画。这也意味着实际应用时的性能上限与模型训练的精度密切相关，但论文并未给出“模型误差多大时 SADQ 仍然优于标准 DQN”的定量判据。后续工作可以通过对 TD 误差传播的分析，建立混合算子在不同模型误差下的固定点上下界，为超参数选择提供理论指导。
- **效率改进方向**：SADQ 的计算开销主要来自对每个候选动作的一步 rollout，而动作空间极大时该成本呈线性增长。未来可考虑采用随机采样候选动作子集、动量更新动力学模型或知识蒸馏来压缩模型预测成本，同时保留动作选择的可靠性。
- **跨域拓展**：虽然论文仅覆盖离散动作空间，但其思想可推广到连续控制——例如通过 CEM 或 PPO 的策略网络生成候选动作，再用模型预测进行筛选。另外，将模型引导的动作选择与离线 RL（如 IQL、CQL）结合，有望缓解离线数据中分布外动作的过估计问题，这是一个自然延伸方向。
