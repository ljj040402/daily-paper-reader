## 摘要
可解释的文本表示应暴露不仅具有预测性，而且对独立审计员来说足够有意义的坐标。现有的判别性表示通常使用匿名嵌入方向，而概念瓶颈和LLM辅助方法将自然语言名字附加到特征上，却不确保这些定义是可复现的或与目标标签不同。我们提出了可解释判别性文本表示的操作性标准：每个坐标应满足概念清晰性（通过独立注释者应用特征定义时经机会校正的一致性来衡量）和标签解纠缠（即特征不应只是对预测目标进行释义）。我们在LLM辅助特征发现（LFD）中实例化这一标准，这是一种迭代方法，从对比结果对立文本对中提出词汇和语义特征，使用跨LLM的Cohen's κ筛选候选特征，并通过残差保留预测增益选择特征。一个示例分析将κ筛选与每个特征的注释噪声界限联系起来，将一致性形式化为可靠性检查。在涵盖七个语料库的十个文本分类任务中，LFD达到了强文本瓶颈基线的预测性能，同时产生了更清晰且更少标签纠缠的特征。由232名评分员进行的人工审计表明，LFD特征在人与人以及人与LLM一致性方面优于基线概念，并且评分员一致认为它们标签泄露更少。这些结果表明，经过一致性测试、标签解纠缠的坐标为可解释文本分类提供了实用的审计标准。

## Abstract
Interpretable text representations should expose coordinates that are not only predictive, but also meaningful enough for independent auditors to apply. Existing discriminative representations often use anonymous embedding directions, while concept-bottleneck and LLM-assisted methods attach natural-language names to features without ensuring that those definitions are reproducible or distinct from the target label. We propose an operational criterion for interpretable discriminative text representations: each coordinate should satisfy conceptual clarity, measured by chance-adjusted agreement between independent annotators applying the feature definition, and label disentanglement, meaning the feature should not merely paraphrase the prediction target. We instantiate this criterion in LLM-assisted Feature Discovery (LFD), an iterative method that proposes lexical and semantic features from contrastive outcome-opposed text pairs, screens candidates using cross-LLM Cohen's $κ$, and selects features by residual held-out predictive gain. A stylized analysis connects the $κ$ screen to a per-feature annotation-noise bound, formalizing agreement as a reliability check. Across ten text-classification tasks spanning seven corpora, LFD matches the predictive performance of a strong text bottleneck baseline while producing substantially clearer and less label-entangled features. Human audits with 232 raters show that LFD features achieve higher human--human and human--LLM agreement than baseline concepts, and raters consistently judge them as less label-leaking. These results suggest that agreement-tested, label-disentangled coordinates provide a practical auditability standard for interpretable text classification.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **现有可解释文本表示的两难**：匿名嵌入方向（如PCA、稀疏探针）预测能力强，但坐标无自然语言名称，无法被人类审计；概念瓶颈模型（如TBM、LaBo）虽然附加了名称，但定义往往模糊、抽象，且易与预测目标标签高度纠缠（label entanglement），导致特征实质上是标签的改述，未能提供真正的解释。
- **本文目标**：提出一个**操作性可解释性标准**——每个坐标必须同时满足**概念清晰性**（独立注释者应用同一特征定义时的一致性，用Cohen's κ测量）和**标签解纠缠**（特征的信息不应只是目标标签的复述）。并以此为指导实现了一个名为**LFD（LLM-assisted Feature Discovery）** 的迭代特征发现方法，旨在生成既预测有效又可直接审计的文本表示。

### 2. 论文提出的方法论：核心思想、关键技术细节、算法流程

- **核心思想**：从社会科学编码实践中借鉴“操作码本+独立编码者一致性”的验证逻辑，将可解释性定义为**可审计性**（auditability），而非仅靠名称的可读性。
- **LFD算法流程**：
  1. **对比配对采样（Pair Sampling）**：每次迭代抽取一对结果对立但文本表面相似（通过TF-IDF或嵌入相似度匹配）的样本，迫使特征关注局部差异，避免宽泛的标签近似。
  2. **特征提议（Proposal）**：由Proposer LLM（Grok-4-fast-reasoning）从两条通道生成候选特征：
     - **词汇通道**：输出可严格匹配的正则表达式（regex），应用时κ=1（自动确定性）。
     - **语义通道**：输出分步阅读理解的编码规则，供独立注释者机械应用。
  3. **跨LLM一致性筛选（κ-gate）**：由独立的Examiner LLM（DeepSeek-chat）根据同一特征定义重新标注数据，计算Labeler LLM（gpt-4o-mini）与Examiner之间的Cohen's κ。仅保留κ ≥ 0.70（Landis & Koch的“substantial agreement”阈值）的候选。
  4. **残差预测增益选择（Selection）**：在训练集上使用LightGBM评估每个候选的增量平衡准确率（held-out BA）。进入残差阶段后，增益计算基于**对已有特征预测残差**的改善，避免重复已捕获的信号。
  5. **终止与剪枝**：若无候选能超过增益阈值δ，或最终移除任何特征后BA不变，则停止。
- **理论分析（Proposition 1）**：在对称等噪声率和条件独立性假设下，跨LLM的κ值界定了每个特征的注释噪声率上限 \(\bar{\eta} \leq (1-\sqrt{\kappa^*})/2\)，进而通过Natarajan等人噪声标签学习的泛化界，将κ=0.70映射为约1.20倍的泛化误差膨胀因子，为κ筛选提供了统计理由。
- **注意**：论文实验中标签解纠缠门（τ=1）被禁用，以测试结构设计本身（对比配对、残差增益）是否自动产生解纠缠特征。

### 3. 实验设计：数据集、基准、对比方法

- **数据集**：共10个文本分类任务，跨越7个语料库：
  - 5个领域/社会科学语料：AdParaphrase（广告改写）、Loan Application（贷款申请，专有）、CFPB Complaints（消费者投诉）、Dec. Reviews（欺骗性评论）、Gaslighting（煤气灯效应）。
  - 2个NLP基准：iSarcasm（讽刺检测）、AG News（分为4个1-vs-rest子任务：Sci/Tech、Sports、World、Business）。
  - 所有任务使用平衡的1000样本子集。
- **对比方法**：
  - **匿名判别性**：PCA on embedding、Sparse Probe（ℓ1-逻辑回归）、Full Embedding（3,072维LightGBM）、Fine-tuned BERT（非线性的上限）。
  - **可解释非判别性**：LDA（主题模型）、BERTopic（神经主题模型）。
  - **可解释判别性**：TF-IDF+ℓ1-logistic（Top-K卡方特征）、TBM（单LLM迭代概念瓶颈模型，基线）。
- **评价指标**：平衡准确率（Balanced Accuracy, BA）。
- **LLM配置**：Proposer = Grok-4-fast-reasoning；Labeler = gpt-4o-mini；Examiner = DeepSeek-chat（跨供应商，避免同族偏见）。TBM使用单gpt-4o-mini（定义+标注）。嵌入使用text-embedding-3-large（3,072维）。

### 5. 实验数量与充分性

### 6. 论文的主要结论与发现

1. **预测性能**：LFD在10个任务上的平均BA（0.708）与TBM（0.707）基本持平，5胜5负。匿名判别性基线仍更高（平均0.763–0.790），但牺牲了可审计性。
2. **标签解缠**：LFD特征的最大|ρ(f,y)|为0.59（Loan Application），而TBM在4个任务（AG News子集）中出现了|ρ|>0.6的近似标签特征（最高0.94）。人工解缠评分上，LFD在所有10个任务上均高于TBM。
3. **概念清晰性**：在人工审计中，LFD特征的人-人平均κ为0.68–0.69（接近0.70实质一致），而TBM仅为0.27–0.45；人-LLM κ方面LFD达0.84–0.99，TBM为0.26–0.43。表明LFD定义能被人类独立复现，而TBM概念实质上是LLM的不透明判断。
4. **共享偏差异步**：在AG-News Sci/Tech的语义通道特征上，LLM-LLM κ比人-人κ高约0.36，表明残差共享偏误存在但可控，对应的泛化膨胀因子约为1.30–1.45（而非理想1.20）。
5. **结论**：一致性测试和标签解缠的坐标提供了实用的可审计标准，LFD在保持预测能力的同时大幅提升了特征的可审计性。

### 7. 优点：方法或实验设计上的亮点

- **操作性定义**：将“概念清晰性”和“标签解纠缠”量化为可测试的指标（κ和|ρ|），为可解释性提供了事先验证标准，而非仅是事后分析。
- **跨LLM一致性筛选**：打破单LLM定义-标注的闭环，利用独立的Examiner保证定义的可转移性，并给出理论噪声界限。
- **对比配对+残差增益**：结构性地驱动特征远离标签改述，无需事后解缠门参数调优（实验中τ=1仍取得良好解缠）。
- **双通道设计**：词汇通道（regex）提供完全确定性，语义通道保留灵活性，并通过κ筛选保证可靠性。
- **丰富的人工审计**：不仅自动评估指标，还组织232名真人标注者对定义清晰性和标签泄露进行独立评估，直接验证了方法的实际效果。
- **理论与实践结合**：将社会科学编码一致性标准引入机器学习，并用VC维泛化界进行理论支撑。

### 8. 不足与局限：包括实验覆盖、偏差风险、应用限制

- **应用范围**：LFD主要适用于规则可表述（rule-articulable）的任务；对于纯组合性信号（如讽刺、欺骗性评论风格），小命名基底的损失是固有缺点，匿名嵌入仍占优。
- **偏差风险**：两个LLM（如GPT-4o-mini与DeepSeek-chat）可能因训练数据重叠共享残余盲区，导致κ膨胀。论文通过实际人-人κ与LLM-LLM κ的对比（+0.36）量化了这一风险，但未完全消除。
- **成本与效率**：LFD的单数据集成本（$5–15, 3–10小时）远高于TBM和匿名基线，不适用于大规模或快速迭代场景。
- **实验设计**：所有结果基于单次数据分裂；未报告多次运行LFD提议管道的方差。消融实验（如单独移除对比配对或残差增益）未做，归因证据尚不充分。
- **标签解缠门参数**：τ=1被禁用，虽然实验显示结构设计足够，但τ作为粒度调节旋钮的实践效果未系统探索。更紧的τ是否会导致过分解、损失信号未验证。
- **泛化界**：Proposition 1是协调度+联合界（coordinate-wise + union bound），并非联合K特征的紧致协变量噪声界，且依赖条件独立性假设（实际中被部分违反）。
